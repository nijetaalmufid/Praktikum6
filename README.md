1. JavaScript adalah bahasa pemrograman yang berjalan di browser untuk membuat halaman web menjadi interaktif.
Kegunaannya: mengubah isi dan tampilan halaman web, menangani aksi pengguna seperti klik, memvalidasi form, dan membuat animasi.

2. jQuery adalah library JavaScript yang membuat penulisan kode JavaScript lebih singkat dan mudah.
Kegunaannya: memilih elemen HTML dengan mudah, mengubah tampilan elemen (misalnya warna, hide, dan show), menangani event seperti klik, serta membuat animasi sederhana.

3. Perbedaan JavaScript dan jQuery:
- JavaScript adalah bahasa pemrograman, sedangkan jQuery adalah library yang dibuat dari JavaScript.
- JavaScript sudah ada di browser, sedangkan jQuery harus ditambahkan dulu (misalnya lewat CDN).
- Penulisan JavaScript lebih panjang, sedangkan jQuery lebih singkat.
  Contoh JavaScript: document.getElementById("kotak").style.display = "none";
  Contoh jQuery: $("#kotak").hide();
- JavaScript lebih cepat dan ringan, sedangkan jQuery sedikit lebih berat karena memuat library tambahan.
- jQuery tidak bisa berjalan tanpa JavaScript, tetapi JavaScript bisa berjalan tanpa jQuery.
